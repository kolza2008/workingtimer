# Working Timer — документация

## Что это за плагин

Working Timer — это расширение для Visual Studio Code. Оно считает время работы в редакторе и показывает его в нижней панели VS Code.

## Что умеет плагин

- Запускать и останавливать секундомер.
- Сбрасывать время.
- Показывать надпись «ПАУЗА», когда секундомер остановлен.
- Ставить секундомер на паузу, если 15 секунд нет активности.
- Снова запускать секундомер, когда пользователь возвращается к работе в редакторе.
- Сохранять рабочие сессии в файл `working-timer-sessions.json`.
- Сохранять данные каждые 10 секунд и при остановке расширения.

## Как определяется активность

Плагин следит за событиями в VS Code:

- перемещение курсора или выделение текста;
- изменение текста в файле;
- переключение между редакторами;
- возвращение фокуса в окно VS Code.

Изменение текста обрабатывается с задержкой в одну секунду. Сохранение файла само по себе не считается активностью.

Если в течение 15 секунд нет подходящих событий, секундомер ставится на паузу.

Важно: плагин не следит за всеми движениями мыши и нажатиями клавиш в компьютере. Он использует только события, которые доступны через VS Code.

## Управление

Секундомером можно управлять нажатием на него в строке состояния VS Code.

В плагине есть команды:

| Команда | Что делает |
|---|---|
| `workingTimer.toggle` | Запускает секундомер или ставит его на паузу |
| `workingTimer.start` | Запускает секундомер |
| `workingTimer.pause` | Ставит секундомер на паузу |
| `workingTimer.reset` | Обнуляет отображаемое время |

Сброс не удаляет сохранённую историю сессий.

## Где хранятся данные

История сохраняется в файл `working-timer-sessions.json`.

Если открыт проект, файл находится в его папке. Если проект не открыт, используется папка данных расширения VS Code.

Для каждой сессии сохраняются два значения:

- `startTime` — дата и местное время начала работы;
- `workTimeSeconds` — продолжительность работы в секундах.

Пример файла:

```json
{
  "sessions": [
    {
      "startTime": "2026-11-25 09:00:00",
      "workTimeSeconds": 900
    },
    {
      "startTime": "2026-11-25 10:15:30",
      "workTimeSeconds": 1800
    }
  ]
}
```

Каждый новый запуск создаёт отдельную запись. Старые записи сохраняются.

## Основные файлы и функции

Основной код находится в `src/extension.ts`.

В нём есть функции:

- `activate()` — запускает расширение и настраивает секундомер;
- `start()` — запускает секундомер;
- `pause()` — останавливает секундомер;
- `resetIdleTimer()` — запускает отсчёт 15 секунд бездействия;
- `activity()` — обрабатывает события активности;
- `save()` — сохраняет сессии в JSON;
- `updateDisplay()` — обновляет время в строке состояния;
- `deactivate()` — сохраняет данные при завершении работы расширения.

## Используемые технологии

- TypeScript;
- Visual Studio Code API;
- Node.js;
- JSON.

## Как запустить проект

1. Открой папку проекта в VS Code.
2. Установи зависимости:

   ```bash
   npm install
   ```

3. Собери проект:

   ```bash
   npm run compile
   ```

4. Нажми `F5`. Откроется новое окно VS Code с запущенным расширением.
5. Найди секундомер в строке состояния.

## Как проверить автоматическую паузу

1. Запусти секундомер.
2. Не взаимодействуй с редактором 15 секунд.
3. Проверь, что в строке состояния появилась надпись «ПАУЗА».
4. Снова измени текст или перемести курсор, чтобы проверить возобновление секундомера.
