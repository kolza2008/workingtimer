## О проекте

**Working Timer** — расширение для Visual Studio Code, предназначенное для учёта времени работы в IDE. Плагин позволяет отслеживать продолжительность рабочих сессий, автоматически приостанавливать секундомер при бездействии и сохранять историю работы в JSON-файл.

## Возможности

- **Секундомер.** Отсчитывает время работы, начиная с нуля.
- **Запуск и пауза.** Позволяет вручную запускать и останавливать отсчёт времени.
- **Сброс.** Позволяет сбросить отображаемое время.
- **Отображение в строке состояния.** Текущее время работы отображается в нижней панели VS Code.
- **Индикация паузы.** При остановленном секундомере в строке состояния отображается надпись «ПАУЗА».
- **Автоматическая пауза.** Если пользователь не проявляет активности в IDE в течение 60 секунд, секундомер автоматически приостанавливается.
- **Автоматическое возобновление.** При возвращении активности в IDE секундомер продолжает работу.
- **Сохранение сессий.** Информация о рабочих сессиях сохраняется в файл `working-timer-sessions.json`.
- **История работы.** Каждая новая сессия записывается отдельно, предыдущие записи не удаляются.

## Сохранение данных

Для хранения истории используется файл `working-timer-sessions.json`.

Данные сохраняются в формате JSON. Для каждой сессии записываются два поля:

- `startTime` — дата и время начала сессии;
- `workTimeSeconds` — продолжительность работы в секундах.

Пример содержимого файла:

```json
{
  "sessions": [
    {
      "startTime": "2026-11-24T10:00:00.000Z",
      "workTimeSeconds": 1800
    },
    {
      "startTime": "2026-11-25T09:00:00.000Z",
      "workTimeSeconds": 900
    }
  ]
}
```

При запуске новой сессии создаётся новая запись. При последующем сохранении обновляется время только текущей сессии.
